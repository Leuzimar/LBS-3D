LBS 3D PWA - VERSÃO CORRIGIDA

Esta versão tem CSS e JavaScript incorporados no index.html, evitando o problema
de o GitHub Pages abrir a página sem estilo quando as pastas não são enviadas.

GITHUB:
1. Crie um repositório público.
2. Envie TODOS os arquivos desta pasta para a raiz do repositório.
3. Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main / root.
6. Save e aguarde o endereço do GitHub Pages.

PWA:
Abra pelo endereço HTTPS do GitHub Pages. No Chrome/Edge use "Instalar aplicativo".

GOOGLE SHEETS:
1. Crie uma planilha.
2. Extensões > Apps Script.
3. Cole google-apps-script.gs.
4. Publique como Aplicativo da Web.
5. Copie a URL /exec.
6. Cole em Configurações no sistema.
7. Em Vendas, use Google Sheets.

Também ficam incluídos css/style.css e js/app.js separados para futuras edições.
